This directory contains screenshots and images for the plugin.

2. `confirmation-modal.png` - Section confirmation modal
3. `daily-note-example.png` - Example daily note

## How to Take Screenshots

1. Open Obsidian with the Daily Report plugin enabled
2. Go to Settings > Daily Report
3. Take a screenshot of the settings page
4. Save as `settings-screenshot.png` in this directory
